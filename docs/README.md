# Ваши наблюдения и передача стенда

Создайте RUNBOOK.md: схема своих VM, адреса, полезная проверка старого документа,
одно управляемое изменение, наблюдаемый отказ и проверенный возврат.
Для каждого наблюдения укажите время, машину и команду.
Храните здесь текст и обезличенные снимки. Пароли, закрытые ключи,
файлы .runtime, auth, дампы и диски VM сюда не копируйте.
Локальный отчёт не заменяет независимую серверную оценку.
